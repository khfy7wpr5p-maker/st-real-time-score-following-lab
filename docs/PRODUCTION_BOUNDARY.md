# Production Boundary

This repository is a research lab, not a production runtime authority.

Not production-ready at SF-00:

- microphone capture,
- realtime follower algorithms,
- performance grading,
- teacher dashboard,
- public inference API,
- production deployment,
- automated learning from user data.

Stable research modules may later be extracted to a C++ realtime core or a separate Performance Intelligence API after benchmark evidence and explicit production activation.
