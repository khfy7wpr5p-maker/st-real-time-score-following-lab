# Ensemble Roadmap

Ensemble research expands only after solo tracking is measurable.

1. Duet: per-part observations + shared beat + global position fusion.
2. Quartet/multi-channel: separate-channel observations, per-part alignment and fusion.
3. Mixed microphone: compare no-separation and separation-assisted strategies.
4. Orchestra: global measure/beat position first; section-level evidence later.

Perfect source separation is not a prerequisite for continuing research. Dense-mix limitations must be measured rather than treated as an automatic blocker.
